# ガンダムウォー 基本ルールのまとめ（叩き台）

版0（2026-11-10）。ナツキの校正待ち。

- 目的：対戦卓の自動化（ターン開始・ダメージ・戦闘の計算）と、将来 Claude が対戦するときの土台。細かい裁定・個別カードの効果は書かない（[GUNDAM WAR Wiki](https://w.atwiki.jp/gundamwar/) が正本）
- 書いた元：Claude の記憶、取り込んだカード文面に出てくる用語（`data/cards_full.json`）、英語版 Wikipedia・ニコニコ大百科の概要。Wiki のルールページはこちらの作業場から読めなかった
- **【要確認n】** の付いた所は自信がない所。末尾の一覧に番号で並べてある

## 1. 用語

| 用語 | 意味 |
|---|---|
| 自軍 / 敵軍 | 自分 / 相手。カード文面の書き方 |
| 本国 | 山札。**残り枚数がそのまま命**（ライフ） |
| 捨て山 | 本国へのダメージで本国の上から移ったカードの置き場 |
| ジャンクヤード | 使い終わったコマンド、廃棄されたカードの置き場（墓地） |
| ハンガー | 一部の効果でカードを置いておく場所 |
| 配備エリア | 場。G・ユニット・オペレーションを置く |
| 戦闘エリア | 宇宙エリアと地球エリアの2つ。戦闘のときだけユニットが出る |
| ゲームから取り除く | 除外。どこにも戻らない |
| ロール / リロール | カードを横にする（使った） / 縦に戻す（使える） |
| 国力 | G などが発生させる力。**使っても減らない**。色つき |
| 廃棄 | 場や手札からジャンクヤードへ送ること |
| 破壊 | 耐久力を超えるダメージ等で起きる。無効にされなければ廃棄される |

## 2. カードの種類と数字

- カード表記 `U-159 緑 1-1-1 C` の真ん中は **指定国力-合計国力-資源コスト**（引き継ぎ書の「カードの読み方」と同じ）
- ユニット：`[格闘力][射撃力][耐久力]` と地形適性（宇宙・地球）を持つ。戦闘に出られる唯一の種類
- キャラクター：ユニットに**セット**して `+格闘/+射撃/+耐久` の戦闘修正とテキストを足す。ユニットとセットされたキャラクターをまとめて「セットグループ」と呼ぶ
- コマンド：手札から使い切り。決められたタイミング（例「(防御ステップ)」）でプレイし、解決後ジャンクヤードへ
- オペレーション：配備エリアに残って効果を出し続ける
- G：国力を発生させる。基本Gは自分の色の国力1。特殊Gは効果つき
- ACE：ユニットとキャラクターが最初から組になったカード

## 3. コストの払い方 【要確認1】

カードをプレイするには、次の3つをすべて満たす。

1. **合計国力**：自軍の国力の合計（ロール済みのGも数える）が、カードの合計国力以上あること
2. **指定国力**：カードと同じ色の国力を、その数だけ発生しているGをロールして払う
3. **資源コスト**：色を問わずGをその数だけロールして払う

- 起動効果の `《R》` はそのカード自身をロール、`《(1)》` は国力1つ分をロール、`《[2・3]》` は「指定国力2・合計国力3」を条件として求める書き方 【要確認2】

## 4. ゲームの準備

- デッキはちょうど50枚（構築の決まりは引き継ぎ書「デッキ構築ルール」）
- デッキを切って裏向きに置き、本国にする
- 先攻・後攻を決める（じゃんけん等）
- 本国から**6枚**引いて手札にする 【要確認3】
- 引き直し（マリガン）の決まり 【要確認4】

## 5. ターンの流れ

各フェイズ・ステップは、まず「規定の効果」（ルールで決まった処理）を行い、そのあと両方のプレイヤーがそのタイミングで使えるコマンドや効果を使える。

### 5-1. リロールフェイズ
- 自軍のロール状態のカードを**すべてリロール**する

### 5-2. ドローフェイズ
- 本国から**1枚引く**
- 先攻プレイヤーの最初のターンは引かない

### 5-3. 配備フェイズ
- **Gを1ターンに1枚まで**手札から配備エリアに出せる（すぐ国力として数える） 【要確認5】
- コストを払って、ユニット・オペレーションを配備エリアに出す、キャラクターをユニットにセットする
- ユニット・キャラクター・オペレーションはそれぞれ1ターンに1枚まで、という決まりの有無 【要確認6】

### 5-4. 戦闘フェイズ
4つのステップを順に行う。

1. **攻撃ステップ**（自軍）
   - リロール状態のユニットを、配備エリアから宇宙エリア・地球エリアへ**出撃**させる（出撃させなくてもよい）
   - 1つのエリアに出たユニットはまとめて1つの**部隊**になり、出したプレイヤーが並び順を決める。いちばん前が**部隊の先頭**
   - 地形適性のないエリアへの出撃 【要確認7】
2. **防御ステップ**（敵軍）
   - 敵軍は、リロール状態のユニットを、自軍の部隊のいるエリアへ出撃させて迎え撃てる。同じエリアにいる敵味方の部隊は**交戦中**になる
3. **ダメージ判定ステップ**
   - 「速攻」を持つユニットのダメージを先に、そのあと残りを同時に 【要確認8】
   - 部隊が与えるダメージ ＝ **先頭のユニットの格闘力＋部隊全員の射撃力** 【要確認9】
   - 交戦中なら、そのダメージを相手の部隊に**先頭から順に**割り振り、耐久力に届いたユニットは破壊される
   - 交戦中でない部隊（迎え撃たれなかった部隊）は、ダメージをすべて**敵軍本国**に与える（**戦闘ダメージ**）。本国の上からその枚数を捨て山へ移す
   - 相手の部隊を全滅させて余ったダメージは本国に行かない（「強襲」を持つ場合だけ行く） 【要確認10】
4. **帰還ステップ**
   - 戦闘エリアにいるユニットは配備エリアに戻り、**ロールする**（規定の効果）
   - 地形適性「地球」を持たないのに地球エリアにいるユニットは破壊される

### 5-5. ターン終了
- 「ターン終了時まで」の効果が切れる。ユニットが受けたダメージも消える 【要確認11】
- **手札の調整**：手札が上限（**7枚**）を超えていれば、上限になるまで捨てる（ジャンクヤードへ） 【要確認12】
- 相手のターンになる

## 6. 勝ち負け
- **本国が0枚になったプレイヤーの負け**（戦闘ダメージでも、引く・カードを使う効果で減っても） 【要確認13】
- 引こうとして本国がないときの扱い 【要確認14】

## 7. 卓（自動化）への当てはめ
今の卓でボタンにしやすい順。

| ルール | 卓でやること |
|---|---|
| リロールフェイズ＋ドローフェイズ | 「ターン開始」ボタン（実装済み。先攻1ターン目のドローなしは未対応） |
| 戦闘ダメージ | 数字を入れて本国→捨て山（自動化①） |
| ダメージ判定 | 先頭の格闘力＋射撃力の合計と、先頭から順に耐久力を超えたユニットを提案（自動化②） |
| 帰還ステップ | 戦闘エリアのユニットを配備エリアへ戻してロール、地球適性なしを提案 |
| 手札の調整 | ターン終了で上限超えを知らせる |
| 勝ち負け | 本国0枚で知らせる |
