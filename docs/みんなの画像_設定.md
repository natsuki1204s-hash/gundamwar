# みんなの画像（Firebase Firestore）の設定

カード画像を仲間全員で共有するための置き場。無料の Spark プランのまま使う（カード登録は要らない）。
画像は Firestore（データベース）の `images` コレクションに、1カード名1文書で入れる。
（画像用の Firebase Storage は今は有料の Blaze プランが要るので使わない）

## オーナー（ナツキ）がやること：1回だけ、10分ほど

1. https://console.firebase.google.com/ を Google アカウントで開き、「プロジェクトを作成」。名前は `gundamwar` など何でもよい。Google アナリティクスはオフでよい
2. 左のメニュー「構築」→「Firestore Database」→「データベースを作成」
   - エディション（聞かれたら）：Standard
   - ロケーション：`asia-northeast1`（東京）
   - 「本番環境モードで開始」
3. できたら「ルール」タブを開き、中身を全部消して下の「ルール」を貼り、「公開」
4. 左上の歯車 →「プロジェクトの設定」→ 下の「マイアプリ」でウェブ（`</>` の印）を押してアプリを登録（名前は何でもよい。Firebase Hosting のチェックは付けない）
5. 出てくる `firebaseConfig` の中の **projectId** と **apiKey** の2つを Claude に渡す（apiKey は秘密の鍵ではなく、公開してよい識別子）
6. Claude が `shared.js` に書いて main に入れたら、全員の卓で共有が始まる

## ルール

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /images/{id} {
      allow read: if true;
      allow create, update: if request.resource.data.keys().hasOnly(['k', 'd', 't'])
        && request.resource.data.k is string && request.resource.data.k.size() < 200
        && request.resource.data.d is string && request.resource.data.d.size() < 600000
        && request.resource.data.t is int;
      allow delete: if false;
    }
  }
}
```

- 読むのは誰でも、書くのは決まった形（カード名・画像・時刻）で 600KB 未満の物だけ。文書を消すのは禁止（外す時は画像を空にして上書きする＝他の人のブラウザの写しも消える）
- リポジトリは公開なので、URL を知っている人なら理屈の上では書き込める。荒らされたら Firebase のコンソールで直すか、ルールの `allow create, update` を `if false` にして止める

## 無料の枠の目安（Spark）

- 保存 1GB：画像は長辺600px・JPEG 80% に縮めてから入れる（1枚 30〜80KB）。1万枚以上入る
- 読み 1日5万回：各ブラウザは前回より新しい物だけ取り、写しを自分のブラウザに持つ。初めて開いたブラウザだけ全部読む
- 超えたらその日は止まるだけで、お金はかからない（Blaze にしない限り）

## しくみ（コード）

- `shared.js`：`window.GW_SHARED = { projectId, apiKey }`。空なら共有は無し（前のとおり各自のブラウザだけ）
- `index.html` の `Images`：起動時と3分ごと（画面が見えている間）に `t` が前回より新しい物を `runQuery` で取り、IndexedDB の `shared` に写す。入れる時は `PATCH`（文書 id はカード名の UTF-8 の16進）。SDK は使わず REST
- 画像の優先：自分のブラウザだけの画像 → みんなの画像 → サイトの `images/` → カード風の枠
- 届いたら `gw-images` の合図でデッキ構築と卓を描き直す
